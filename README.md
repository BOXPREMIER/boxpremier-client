## **📁 Estructura del proyecto**

`/boxpremier-client`    
  `├── src/`    
  `│   ├── assets/             # imágenes y recursos estáticos`    
  `│   ├── components/         # componentes UI (Navbar, FooterBar, AuthForm)`    
  `│   ├── layout/             # estructura general de la app`    
  `│   ├── pages/              # vistas principales (Home, MainPage, ProfilePage, SubscriptionPage)`    
  `│   ├── router/             # configuración de rutas`    
  `│   ├── services/           # conexión con API mediante Axios`    
  `│   ├── store/              # estado global`    
  `│   ├── tests/              # pruebas unitarias con Jest`    
  `│   └── validators/         # validaciones de formularios`    
  `│`    
  `├── public/                 # archivos públicos`    
  `├── vite.config.js          # configuración de Vite`    
  `├── package.json            # dependencias y scripts`    
  `└── README.md`

## **⚡ Instalación y ejecución**

`# 1. Clonar el repositorio`    
`git clone https://github.com/tuusuario/boxpremier-client.git`    
`cd boxpremier-client`  

`# 2. Instalar dependencias`    
`npm install`  

`# 3. Ejecutar el proyecto`    
`npm run dev`  

🌐 **Frontend:** [http://localhost:5173](http://localhost:5173)
